# FT-897 CAT Controller

This PyQt5 application provides a simple control panel for the Yaesu FT‑897 transceiver.

## Features

- Connect to the radio via serial port
- Display the current frequency, S‑meter and operating band
- Send CAT commands for quick band selection via the **Pásmo** menu
- Transmit control with the PTT button
- Support for dark/light/contrast themes and adjustable fonts

## Running

```bash
python3 ft897_gui.py
```

Select the appropriate serial port from the drop‑down list and click **Připojit** to connect.
