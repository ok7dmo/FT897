# FT897

Simple PyQt5 CAT control for the Yaesu FT-897.

## Requirements

- Python 3
- PyQt5
- pyserial

## Usage

Run `python3 ft897_gui.py` and choose your serial port from the drop down.
The frequency and S-meter labels always use the largest possible font and stay
the same size so the display remains stable for visually impaired operators.
