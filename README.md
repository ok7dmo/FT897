# FT897

This project provides a simple PyQt5 application to control the Yaesu FT-897 transceiver over a serial CAT interface.

The app can also download the radio's memory channels via Clone Mode. Use the
menu item **Paměti → Load memories from radio…** and follow the on-screen
instructions. Parsed channels appear under **Paměti → Radio**.

## Requirements
Install dependencies using pip:

```
pip install -r requirements.txt
```

## Running
Execute the application with Python 3:

```
python app.py
```
